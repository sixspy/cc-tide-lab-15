# 潮切

中文名：**潮切** · 前缀 `tide` · 端口 **7900**

## 骨架（新骨，不是闸对/对拍/缝包换皮）

**观测点装载 → 事件时入窗缓冲 → 关窗物化切片 → 迟到/乱序旁路 → 窗账与缓冲互证**

| 对比 | 闸对 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→开腿→成对 | 双轨装载→键对齐 | **单流入→入窗缓冲→关窗物化** |
| 在途 | 开腿账 | 悬账单（对齐后） | **入窗缓冲（未关窗）** |
| 产物 | 行程账 | 对齐差+结论 | **窗切片账** |
| 旁路 | 旁路匣 | 悬账/缺边 | **迟到匣（事件时出窗）** |

皮：物流网点运单轨迹上报。去皮：**事件时关窗管道 + 缓冲 + 迟到旁路 + 窗贯验**。  
禁止做成运单 CRUD、配送看板、工单系统。禁止抄闸对开腿/对拍左右轨命名。

## 页面（真翻页）

潮切台 · 观测流 · 入窗缓冲 · 窗切片账 · 迟到匣 · 窗贯验 · 网点源 · 窗规

## 空桩（邻题扩展）

`事件时严格入窗` · `处理时缓冲再裁` · `关窗半截回滚` · `迟到旁路保留` · `乱序重排入窗` · `窗键幂等` · `跨窗禁拼` · `空窗封印` · `网点时钟漂移` · `日界切开关窗` · `多源串扰隔离` · `切片键契约` · `强制关窗` · `迟到升格回放` · `缓冲溢出策略` · `关窗封印写闸` · `三联窗贯验` · `装载批失败闭` · `窗水位推进` · `观测点换绑`

题面写 `现状：\`空桩名\` 空桩`，与目录同字。枚举：`GET /api/空桩`。

## 已落地：缓冲溢出策略

窗规两键与窗规同票：`入窗缓冲阈值`（0=不限，基线照单全收）、`缓冲溢出策略`（`切流拒` / `双写归档`）。

- **切流拒**：超阈整票拒，窗内点一条不进现行缓冲，全部入 `溢出裁决账`（命运`溢出拒收`）并钉水位指纹（拒因+指纹），现行缓冲条数不涨。
- **双写归档**：阈内点进现行缓冲，溢出点进只读归档旁路（命运`溢入归档`）；两轨读引用不同，现行缓冲永远不越阈值。
- 读阈/数水位/写命运在同一 `BEGIN IMMEDIATE` 写事务内，并发超阈不双成功、不双涨；溢出点与窗内点、迟到点分轨不混计。
- 只读接口：`GET /api/溢出裁决`（阈值、现行条数、拒因或归档键、水位指纹、valid）、`GET /api/溢出裁决账`（归档旁路）。
- 夹具：`超阈样例`（6 个窗内点，阈值设 4 即可见超阈）。潮切台可改阈值/策略并看水位卡片。
